# 坦克大战(超前瞻远古demo测试版本)

> 完成于 2026.06.27 —— 这是我在GitHub上发布的第一个可运行的，具有基础功能的游戏版本

---

## 操作方式

- **W A S D**: 控制坦克的移动
- **鼠标移动**: 用来控制炮管的瞄准方向
- **鼠标左键**: 开火
- **R**: 游戏结束后重新开始
- **ESC**: 退出游戏

---

## 关于这个版本

这是一个用Python和Pygame实现的坦克对战游戏
目前只有两个坦克，一个是玩家，一个是敌方ai
敌方ai具备基础的A\*寻路能力，可以绕墙追踪玩家，并且具备基础的射击和躲避子弹能力
规则：绿色为玩家坦克，红色为敌方坦克，没有血量，碰到子弹就死亡，单个坦克发射的子弹最多存在6颗

此版本仅作为个人学习项目的第一步，不代表最终品质

---

## 运行方式

直接运行main.py(需要Python环境)
